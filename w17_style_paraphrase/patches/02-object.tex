\paragraph{The store.} A frozen encoder maps each training item to a latent. The latent
space is partitioned without labels into $K$ wells by a balanced correlation partition, and in
each well the store keeps the leading principal subspace of the fit pool, with the pool mean as
the first atom. No label enters the content. We write $n$ for the number of factors a request
composes jointly and $K$ for the number of wells, and never write either as $k$.

\paragraph{The read.} A request is a tuple of factor values. A tensor-product address book,
fitted on the fit pool, maps the request to per-well coefficients; the read renders
$x_k=U_k c_k$ in each well's orthonormal basis and the frozen decoder the image.
The read is request-only: no feature tensor enters it, as asserted on the deployed object
(bitwise stable under feature perturbation over 64 checks at $\Kstar$).
