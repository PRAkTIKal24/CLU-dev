## THE ANOMALY SCORE IS ITSELF THE EXPERIMENT (Head, 2026-07-19)
There is no single "right" anomaly score — **finding it is a G7b sub-result.** The first CSF pass runs **both** primary scores as parallel arms and compares them; the choice is made from the data, and a hybrid is tried only if it beats both individuals. Build the machinery so the comparison is one experiment.

**First-pass arms (both first-class, both required):**
1. **`energy` / `residual`:** anomaly score = `H(q,p)` of the state after a fixed relaxation, or the **relaxation residual** `R0` (how badly the window fails to settle into a basin) — the EBM reading: anomalies are high-energy states that do not relax. Connects to the paid-access/gate story. **CM-3 discipline (binding): NEVER claim energy is a *superior* signal to a reconstruction baseline; claim it is a *physically-grounded* one carrying guarantees the baselines lack. The honest head-to-head is the result.**
2. **`predict`:** anomaly score = multi-step prediction MSE of the CLU rollout over the window. The conventional TSAD framing and the fairest head-to-head vs PCA-recon.
3. **`hybrid` (iteration 2, only if warranted):** a documented combination (e.g. energy-gated prediction error). Build the hook; **do not tune it in the first pass** — it is the *final* iteration, tried only if it beats both singles.

**Metrics: VUS-PR AND ROC.** The harness gives VUS-PR (primary, per the eval charter). **Add ROC-curve / AUROC output** per score arm so the Head can see the operating-characteristic differences, not just a single scalar — this is how the score-mode choice will actually be made. Emit the raw score/label arrays so ROC curves can be re-plotted without re-running.

**PARKED future score idea (record, do NOT build — Head, 2026-07-19):** *settling-time as a score* — the number of rollout steps to fall into a latch. Low ⇒ the window matched something in permanent memory ⇒ nominal (trained-on); high/never-settles ⇒ coarse anomaly signal. **Explicitly deferred:** it is explored only *after* the first CSF results, and **may be dropped entirely if energy/MSE are already publication-worthy.** Add a one-line `# FUTURE: settling-time score (handover 2026-07-19)` marker where a third score_mode would slot in, and nothing more.
