## The result to check
1. **The no-go (CM-17).** Any Markov chain whose last substep is an **additive Gaussian kick with fixed covariance** has a **Gaussian-smoothed** invariant momentum marginal. When the kinetic energy is **not quadratic**, the Gibbs momentum marginal is not Gaussian (for the relativistic `T(p) = c√(pᵀM⁻¹p + m₀²c²)` it is **Maxwell–Jüttner**, whose characteristic function decays like `e^{−m₀c|t|}`). ⇒ **no noise scale σ gives such a sampler a Gibbs invariant.** The proof is a characteristic-function argument; it needs neither `V=0` nor linear damping.
2. **The control parameter is `d·Θ`**, `Θ = T/(m₀c²)`, not `Θ` — the defect grows with dimension. Ultra-relativistically `Var_MJ/(M_eff T) → (d+1)Θ`.
3. **The exact fix.** Maxwell–Jüttner is a **Gaussian scale mixture**: `p|s ~ N(0, M/(2s))`, `s|p ~ InvGauss(mean c²/(2T·T(p)), shape c²/(2T²))`. So the correct thermostat is **the same Gaussian O-step with a randomized inertia equal to the relativistic mass `m₀γ_Lorentz`** — one inverse-Gaussian draw per step. It **dominates** an exact MJ momentum refresh because it preserves momentum persistence.
