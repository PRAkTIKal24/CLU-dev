# xy-lattice-theory — physics-theorist report

**Task + acceptance criterion:** establish or refute — *a lattice of SO(2)-designed CLU registers at temperature T, with FDT-correct noise and no governor, is an XY model on the coupling graph (more generally an O(n) model), so that equilibrium memory of the array is governed by classical statistical mechanics: a single register always forgets, a ≥2D array can have a phase that remembers.* Derivation + cheap numerics + an experiment spec.

**Status: done.** The claim **survives, with three corrections that change its content**, one of which sharpens it into (I think) a better thesis. Two shipped code defects found, one **blocking**. Repo read-only.

## 0. Headline

> **The reduction is exact — for the *designed* coupling only.** Restricting the joint Hamiltonian of a `channel_spring_coupling` lattice of `so2_invariant` units to the product of vacuum rings gives **exactly** `V = Σ_⟨ij⟩ 2κr*²(1 − cos(θ_i−θ_j))`, a pure first harmonic with **J = 2κr*²** (verified to 2.2e-16, all other harmonics ≤ 7.4e-18). With FDT noise, γ>0 and no governor, the CLU Langevin's configurational marginal **is** the XY Gibbs measure at the *same* T (verified: ⟨cos Δθ⟩/Gibbs = **1.0003 ± 0.0022** (sd, 9 cells; max deviation 0.41%) across γ ∈ {0.02, 0.1, 0.4} and T ∈ {0.02, 0.05, 0.1}).

> **But the *shipped* coupling is not an XY model, and a trained one is not either.** The repo default `spring_coupling` (learnable `W ~ N(0, 0.1²)`) breaks the global U(1). At init: `P(J<0) = 0.52` (the exchange is antiferromagnetic half the time), median `h₂/|J| = 1.00`, median U(1)-breaking/`|J|` = 1.48. After 400 epochs of wake training on data generated by a *ground-truth XY lattice*: `J/J_true = 0.019, 0.018, −0.004` (3 seeds) while `h₂/|J| = 0.61, 0.71, 2.15`. Initialising the same learnable projections **conformal** (`W = I₂`) recovers `J/J_true = 1.034, 1.070, 1.037` with `h₂/|J| ≤ 0.017` — **at equal or better fit loss.** So the symmetry breaking is a *parameterisation/init* artifact, not something the objective wants, and the fix is free.

> **The correction that matters most.** "A ≥2D array has an equilibrium phase that *remembers*" is true, but **not of a written pattern** — equilibrium forgets any generic pattern in every dimension. What a 2D array below `T_KT` remembers is **topological**: the winding numbers `(w_x,w_y) ∈ π₁(S¹)² = ℤ²`. Their Arrhenius lifetime is `τ ∝ L^{πρ_s/T − 2}`, and the exponent vanishes **exactly at** `T_KT` by the Nelson–Kosterlitz universal jump `ρ_s/T → 2/π`. **The KT transition *is* the memory transition** — it is precisely the temperature at which the topological register's lifetime stops growing with system size. The same `π₁` that bounds a *single* register's dynamic range (deep-dive §6 aliasing) is the one that creates the vortices. Aliasing and vortices are the same winding.

Two dictionary errors in the task statement, both load-bearing, are corrected in §2: **ρ_s ↔ J = 2κr*², not F²**; and **n = dim(G/H) + 1, not dim(G/H)**.

## 2. Item 1 — the reduction (the load-bearing step)

### 2.1 The architectural fact [proven by construction; verified]
`SO2InvariantPotential` is `V_i(q_i) = f_θ(r_i²) + α r_i² + g_θ(spectators)` — exactly SO(2)-invariant on the channel. So restricted to the product of vacuum rings, `V_i` is **constant in θ_i**, and

> **all θ-dependence of the joint `V` comes from the couplings.**

*Verified:* the 2-D FFT of the real `lat.V` on the trained vacuum torus has residual power **outside the quadratic band ≤ 4.2e-32** (float64 floor) for all 6 trained lattices — i.e. `V|_torus` is exactly `{(0,0),(±1,0),(0,±1),(±2,0),(0,±2),(±1,∓1),(±1,±1)}`, as the quadratic coupling demands.

### 2.2 Prop 1 — the designed channel spring is EXACTLY XY [proven; verified]
With `channel_spring_coupling` (`W_i = W_j = 𝟙` on the channel), on `r_i = r_j = r*`:

```
V_c = κ‖q_i − q_j‖² = 2κ r*² (1 − cos(θ_i − θ_j))
```
a **pure first harmonic**, `J = 2κ r*²`, exact to all orders (no `cos 2Δθ`, no anisotropy).

*Verified (`s1_reduction.json`):* `|J_meas/J_pred − 1| = 2.2e-16`, `max|other harmonic| = 7.4e-18`, for unit dims `d = 2` and `d = 4` (spectators present).

### 2.3 Prop 2 — the general harmonic content of a learnable spring [proven; verified]
Let `A_i = W_i[:, :2]` (channel block), `β = W_i^{sp}s* − W_j^{sp}s*`, `S_i = A_iᵀA_i`, `C = A_iᵀA_j`. On the torus:

```
V_c/κ = const
      + r*²[ (S_i,00−S_i,11)/2 · cos2θ_i + S_i,01 · sin2θ_i ]     ← p=2 single-site anisotropy (site i)
      + r*²[ … same for j … ]                                      ←                              (site j)
      + 2r*[ (A_iᵀβ)_0 cosθ_i + (A_iᵀβ)_1 sinθ_i ]                 ← p=1 field (only if spectators couple)
      − 2r*[ (A_jᵀβ)_0 cosθ_j + (A_jᵀβ)_1 sinθ_j ]
      − 2r*²[ a·cos(θ_i−θ_j) + b·sin(θ_i−θ_j) ]                    ← XY exchange + Dzyaloshinskii–Moriya
      − 2r*²[ d₁·cos(θ_i+θ_j) + d₂·sin(θ_i+θ_j) ]                  ← BREAKS the global U(1)
a = (C₀₀+C₁₁)/2,  b = (C₁₀−C₀₁)/2,  d₁ = (C₀₀−C₁₁)/2,  d₂ = (C₀₁+C₁₀)/2
J ≡ 2κ r*² a = κ r*² · tr(A_iᵀA_j)
```
*Verified:* analytic coefficients vs a direct 2-D FFT of the real `SpringCoupling.__call__`, `max|analytic − numeric| ≤ 1.4e-17` across `(d,k) ∈ {(2,2),(4,2),(4,3)}`.

### 2.4 Cor — the exact U(1) condition [proven; verified]
`V_c` is invariant under the simultaneous rotation `θ_k → θ_k + c` **iff**
1. `S_i ∝ 𝟙₂` and `S_j ∝ 𝟙₂` (each `A` is a **conformal** embedding `ℝ²→ℝ^k`), **and**
2. `C = A_iᵀA_j ∈ span{𝟙, ε}` (a *complex-linear* overlap), **and**
3. the `β` field terms vanish.

Then `V_c = const − 2κr*² c_i c_j cos(θ_i − θ_j − Δφ)`: **pure XY with a DM phase** `Δφ` = the relative rotation of the two projections.
*Verified:* with `A = c·R(φ)`, `h₂ = 4.8e-19`, U(1)-breaking `= 1.3e-18`, and `J`, `DM` match the closed forms to 1e-15.

> The DM phase is **pure gauge on a tree** (absorb `θ_i → θ_i + Σ_path Δφ`), but on a **cycle** it is a flux → frustration. A ring/torus lattice with learned projections is therefore a *frustrated* XY model, not a clean one. [proven; not simulated]

### 2.6 Prop 3 — Born–Oppenheimer dressing: what the radial (massive) modes do [proven; verified]
Radii are not frozen. With `U` the unit's radial potential, `k_r ≡ U''(r*) = M_ch μ_rad²`, `c ≡ 1 − cosΔθ`:

```
V(r_i,r_j,Δθ) = U(r_i)+U(r_j)+κ(r_i²+r_j²−2r_i r_j cosΔθ)
ρ = −2κ r* c / k_r            ← the ring CONTRACTS when misaligned
V_BO = const + 2κr*² c − (4κ²r*²/k_r) c²
⇒  J₁ = 2κ r*² (1 − 4κ/k_r)        (exchange WEAKENED by radial breathing)
   J₂ = 2κ² r*² / k_r              (a SECOND HARMONIC is generated)
   J₂/J₁ = (κ/k_r)/(1 − 4κ/k_r)
```
> **The XY reduction is controlled by one dimensionless ratio, `κ/k_r` = (coupling spring constant)/(radial spring constant).**

*Verified (`s2_born_oppenheimer.json`, exact minimisation of the real `CLULattice.V`):* over `κ/k_r ∈ [1.25e-4, 0.0625]`, `|J₁/J₁^pred − 1| ≤ 4.4e-16`, `|J₂/J₂^pred − 1| ≤ 1.4e-13`, `|J₃/J₁| ≤ 3.8e-17`, radial asymmetry `|r_i − r_j| ≤ 2.3e-8`. For the **quartic** Mexican hat this formula is **exact to all orders** (because `V` is quadratic in `x = r²`: `V_BO = 2κf²c − κ²c²/(2λ)` exactly); for a general `U` it is the leading term in `κ/k_r`.

**Cor (ring collapse).** The BO solution needs `x = f² − κc/(2λ) ≥ 0` up to `c = 2` ⇒ **`κ < λf² = k_r/8`**. Beyond it the anti-aligned configuration collapses the ring to the origin (measured at `κ=1.0, k_r=8`: `J₃/J₁ = −2.41`, radial asymmetry 2.0 — the `i↔j` symmetry breaks). Generally `κ < |U''(0)|/4`.

**Where the program actually sits:**
- `v3-lattice-build`'s pricing sweep (λ=f=M=1 ⇒ k_r = 8, κ ∈ [0.003, 0.3]) ⇒ `κ/k_r ∈ [3.8e-4, 0.0375]`, `J₂/J₁ ≤ 4.4%`. **Safely XY.** ✅
- The **trained** designed-SO(2) checkpoints (t-lever: `M_ch ≈ 0.66–0.69`, `μ_rad² ≈ 0.67–1.35` ⇒ `k_r = M_ch μ_rad² ∈ [0.458, 0.927]`) at the default `kappa_c = 0.05` ⇒ `κ/k_r ∈ [0.054, 0.109]`, i.e. **`J₂/J₁ ≈ 5.4–10.9%` at leading order** (the quartic-hat resummation `(κ/k_r)/(1−4κ/k_r)` would give 6.9–19.4%, but that resummation is exact only for a quartic `U` and should not be trusted on a learned radial profile). Ring-collapse threshold `κ = k_r/8 ∈ [0.057, 0.116]` ⇒ **the default `κ_c` sits within a factor 1.15–2.3 of collapse.** ⚠ Flag for any lattice built on those checkpoints.

## 3. Item 2 — the dictionary, stated rigorously

### 3.1 Momentum marginalisation [proven; verified]
`π(q,p) ∝ e^{−H/T}`, `H = T(p) + V(q)`. `p` is a **flat Cartesian** coordinate, so `∫dp e^{−T(p)/T}` is `q`-independent **for any `T(p)`** — Newtonian or relativistic, any mass matrix `M`. Hence the configurational marginal is **exactly** `e^{−V(q)/T}`.

> **[proven] The inertial mass matrix and the kinetic mode do not affect the equilibrium statistics at all.** They affect only the dynamics.

*Verified (`s4b`):* `anisotropic_M` arm, channel masses `(0.4, 2.5)` (6.25× ratio), FDT noise: `⟨cosΔθ⟩/Gibbs = 1.0002, 1.0009, 1.0003` at `T = 0.02, 0.05, 0.1`.
This is worth stating in CLU language because F5's kinetic-isotropy constraint is a **dynamical** requirement (Noether-charge drift), *not* a thermodynamic one. `tie_channel_mass` is irrelevant to the XY thermodynamics.

Integrating out the radii (measure `r dr`) then gives, up to the Prop-3 dressing,
```
P({θ}) ∝ exp( (1/T) Σ_⟨ij⟩ J cos(θ_i − θ_j) ),     J = 2κ r*²
```
the classical XY model at inverse temperature `1/T_Langevin`.

### 3.2 The dictionary — with two corrections

| XY / O(n) object | CLU object | note |
|---|---|---|
| `β = 1/T_XY` | `1/T_Langevin` | **only** with `fdt` noise, γ>0, no governor, `newtonian_learned` |
| exchange `J` (per bond) | `2κ r*² = 2κ F²/M_ch` | exact for the designed coupling |
| **spin stiffness `ρ_s(T→0)`** | **`J = 2κ r*²`** | ⚠ **NOT `F²`** |
| spin-wave velocity | `a√(2κ/M_ch)` | ⇒ sync `∝ κ^{−1/2}` |
| moment of inertia (dynamics only) | `F² = M_ch r*²` | sets `D_θ`, cancels from the statics |
| lattice sites / bonds | CLU units / coupling-graph edges | |

> ⚠ **Correction 1 (the task's `ρ_s ↔ F²` is wrong).** `F²` is a *temporal* stiffness — an inertia — and it **cancels out of the Gibbs measure**. The *spatial* stiffness that appears in Mermin–Wagner and KT is the exchange `J = 2κr*²`. Both carry `r*²` (the decay-constant/condensate factor), but `F²` carries `M_ch` where `ρ_s` carries `2κ`. `F²` is a stiffness only in the **0+1D** sigma model of a *single* register (`S = ∫dt ½F²θ̇²`, deep-dive §5), where it sets `D_θ`.

> ⚠ **Correction 2 (`n = dim(G/H) + 1`).** The O(n) model's spins live on `S^{n−1}` = the vacuum manifold; **#Goldstone modes = dim(G/H) = n − 1**.
> - Z₂ double-well coset (dim 0, 0 Goldstones) → **Ising, O(1)**
> - `SO(2)` register, `M = S¹` (dim 1, 1 Goldstone) → **XY, O(2)**
> - `SO(3)/SO(2)` register, `M = S²` (dim 2, 2 Goldstones) → **Heisenberg, O(3)**
>
> "n = dim(G/H)" would label our SO(2) register `n=1` = Ising — precisely the error the task's own discipline note forbids.
> **And O(n) universality only applies when the coset is a sphere.** The abelian torus bank `T^k` recommended by deep-dive §7 has `M = (S¹)^k` → `k` *decoupled* XY models (diagonal coupling), **not** an O(k+1) model. In general the class is that of the `M`-valued sigma model.

### 3.3 `π₁(G/H)` does double duty [proven + standard]
Deep-dive §6: `π₁ = ℤ` bounds a *single* register's dynamic range (writes alias at `p_crit = 2π M_ch r* γ/ε`). The **same** `π₁` decides whether a 2D array has topological defects (vortices) and hence a KT phase. **Aliasing and vortices are the same winding.**

| coset `M` | `π₁` | single register | 2D array |
|---|---|---|---|
| `S¹` (SO(2)) | `ℤ` | aliases at `p_crit` | **KT transition** at `T_KT` |
| `T^k` (abelian bank) | `ℤ^k` | `k`-fold aliasing | `k` decoupled KT transitions |
| `S²` (SO(3)/SO(2)) | `0` | **no aliasing** (§6) | **no KT**: 2D O(3) is asymptotically free, `ξ ~ e^{2πρ_s/T}` — finite at every `T>0` |

> **This is the precise answer to "what do multiple symmetry modes buy?"** A non-abelian (spherical) bank buys freedom from aliasing and pays with the *loss of any thermodynamic memory phase in 2D*. An abelian torus bank keeps `k` independent KT phases and pays with `ℤ^k` aliasing. Capacity and thermodynamic stability are traded through the same topological invariant.

> - *"Anneal T to search structure"* — **needs a caveat.** The number of accepted structural moves you can afford **per register half-life** is maximised at **`T = B`**, not at `T→0` and not at `T→∞`. Cold is not free: at `T ≪ B` the search freezes exponentially while erasure only slows as `1/T`.
> - Cost of γ (honest): γ does not slow structural search *per step*, but it slows the *massive* sector's relaxation (`rate ∝ ε²μ²/γ` overdamped), so if `ΔH` depends on equilibrated massive modes, the ledger goes stale.

**CM-3 discipline.** None of this claims CLU searches structure better than simulated annealing on a graph. It claims **certificates**: (1) the `ΔH` of a gate flip is an exact, bounded, closed-form ledger (`V_c` is quadratic; the annealed-gate free energy is bounded by `w·ln(1+e^{t/w})`); (2) the register's erasure law `D_θ` is exact and measured to 0.7% (t-lever); therefore (3) the exchange rate `N_moves(γ,T,B,Δ,F²)` is computable **a priori, before running anything.** The claim is *predictability*, not signal superiority.
