2. **The crux (weak-form addressing) splits cleanly into a solved half and a measured-dead half.** The gradient-through-rollout objection itself is answered: symplectic reads never have vanishing gradients (‖J‖≥1 always), and in the regular regions where the memory structures live, gradients grow only **linearly** in horizon (measured log-log slope 1.0014); the exponential catastrophe is confined to chaotic regions (measured λ=0.098; **44.8 orders of magnitude** worse at t=1000). **The memory-useful structures and the gradient-benign structures are the same set.** BUT my pre-registered restructuring prediction **failed**: from a deliberately-bad address, **escape and transport are learnable** (9/18 basin-level, median loss 7.90→~2.9) while **capture — cross-basin re-localization — fails under all four protocols tried** (plain GD 2/18, Adam 1/18, GD-then-dissipative-capture 3/18 ≈ chance, energy-annealed 0/18; §5). The failure mechanism is identified (separatrix roughness / chaotic scattering). **Consequence: blind read-side address search across basins is dead; the architecture must use derived addresses (codebook = function of the landscape), write-side restructuring, and retry-as-capture (§5)** — all three of which are more, not less, aligned with the Head's vision (the writer knows where it wrote; the boost-retry cascade becomes load-bearing).
3. **The sharpest inversion of the folk objection: dissipation, not conservation, is what kills address gradients.** A damped (γ>0) read relaxes to a basin fixed point — the read becomes piecewise-constant in the address, gradient ≈ (1−γ)^n ≈ 0. Measured in the most dramatic form available: the damped-read GD arm's loss is **frozen at 7.9035443… to 7 significant digits over 4000 GD steps** (0/18, exactly as pre-registered). Conservative reads are rough but gradient-transparent. **Retrieval robustness (contraction) and address learnability (gradient flow) pull γ_read in opposite directions, and §5 shows no γ-schedule resolves it for cross-basin search** — the resolution is to stop searching addresses by gradient at all (derived addresses + retry-as-capture, §5).
4. **Mass is a real key, but not the kind the vision assumed, and not in the shipped code.** Proven: scalar mass with p₀=0 addresses **timescales only** (exact √M time dilation, incl. relativistic); with p₀≠0 it addresses **energy shells** (which basins are enterable — threshold verified); anisotropic mass addresses **shape**. And crucially: **as shipped, mass is a global model parameter, not an address** — every rollout shares it. Making the vision's step (5) meaningful requires masses to be **per-launch attributes** supplied by the address selector. Once per-address, the D1 frozen-mass threat dissolves: relative masses are exactly learnable (Toy E: to 2.2e-14) even while the global scale stays D1-frozen (corrected partition `η_m/(η_m+Kη_k)`, matched to 13 digits).
5. **Capacity has three regimes, not one number** (measured, §4): barrier-protected discrete items (perfect selectivity up to a packing bound), a **washboard death zone** at intermediate packing (selectivity crashes to 0.49 — this is where v5-gate's 1–1.6-bit emergent registers live), and a **continuum-register regime** past the merger where selectivity *recovers* (0.96) and capacity is set by write precision, not dynamics. The program's designed-vs-emergent split is the difference between operating in regime 3 vs being stuck in regime 2.
6. **SDR moves from side-quest to prerequisite — confirmed, with a sharpening** (§7): the division of labor is forced by T2/T3 (regularizer/design supplies *existence/non-degeneracy* of the codebook; the loss supplies *assignment*), but **mode-(a) permanent latches cannot come from any finite-λ soft regularizer** (R-4 gives μ²(λ)>0 ⇒ finite half-life; the measured designed-vs-emergent flatness gap is 12 orders). Permanent memory must be **designed-in structural blocks**; SDR keeps everything else alive and restructurable.

## 1. The formal object (item 1) — Hub's formalization accepted with three corrections

**State space.** Phase space `Γ = ℝ^{2d}` with symplectic form ω; a landscape `V_θ`; a kinetic family `T_{m}(p)` indexed by a **per-launch** mass vector `m ∈ ℝ₊^d` (correction 1 below); read dissipation `γ_r ≥ 0`; the flow map `Φ^N_{m,γ_r}: (q₀,p₀) ↦ (z_1,…,z_N)`.

**Memory** is the pair `𝕄 = (V_θ, 𝒜)` where `𝒜 = {a_i} = {(m_i, q₀ᵢ, p₀ᵢ)}` is the **address codebook**. The memory is *in the landscape*; the codebook is the index. (Hub's core claim: accepted.)

**Stored item** = a triple `(S, ρ, τ)`:
- `S ⊂ Γ` an invariant or slowly-decaying structure of the flow: a basin/fixed point `(q*,0)`, a periodic orbit / invariant torus, a coset orbit (register), or a broken-vacuum point set;
- `ρ` : trajectories near `S` → payload — the content, required to be **linearly decodable** from the trajectory (the program's read bar). Payload channels available: *location* (`q*`, d reals), *spectrum* (local Hessian frequencies — readable as trajectory frequencies), *register value* (coset coordinate, 1 real per designed register), *identity* (which basin — log₂K bits);
- `τ` = retention: `τ=∞` iff `μ²_S = 0` exactly (latch; designed-only, CM-16a); else `n₁/₂ ∝ γ/(T)` diffusive for flat, V-curve `n₁/₂(γ)` with minimum at `γ_crit = 2εμ` for massive (t-lever/v5-gate laws imported unchanged).

**Write** = a parameter displacement `δθ` that creates/moves `(S, ρ, τ)`. The **write current** for a register is exactly F5/Prop-17's *equivariant write current*: the tilt direction in θ-space that transports the coset value along the symmetry orbit at zero μ² cost. Write modes (a)/(b)/(c) = choices of the target `μ²` and location; §6.

**Read** = launch `a`, collect `Φ^N(a)`, apply linear functional(s). Two physically distinct read modes (correction 3):
- **γ_r = 0 (conservative read):** location-addressable; trajectory depends smoothly (regular regions) on `a`; information-preserving at any horizon (measured: selectivity identical at N=2000 and N=20 000); gradient-transparent (§2 Prop 4).
- **γ_r > 0 (dissipative read):** content-addressable — the basin of attraction *is* the similarity metric (this is exactly Hopfield retrieval, and is what `q*`-scoring already does on CAFE); robust to address noise; but gradient-opaque (§2 Prop 5) and it erases the within-basin payload as it settles.

**Address** = `(m, q₀, p₀)` with the roles now sharp (from §2): `q₀` selects *location*; `(m,p₀)` jointly select the *energy shell* `E = T_m(p₀) + V(q₀)` (= which barriers are crossable = scope); `m` alone selects *timescale* (and, anisotropically, shape); the governor bounds *reach* `|q_i(N)−q_i(0)| ≤ Nεc/√M_i` (latency/scope guarantee). **Correction 1 (load-bearing):** in the shipped code `log_mass` is a *model* parameter shared by all rollouts — **as shipped, `m` is not an address component at all**; the architecture requires the address selector to emit `m` per launch (see "Engineer specs" at the end). **Correction 2:** `p₀` is not a passive part of the address; it is the *energy-budget key*, and the boost-retry (§7) is precisely a ladder on it.

## 2. Six propositions (the physics that constrains the design)

**Prop 1 (mass = time dilation; proven + verified).** For scalar mass `M` and any kinetic of the form `T = τ(‖p‖²/M)` — Newtonian and the shipped relativistic both are — the canonical substitution `p = √M p̃`, `t = √M t̃` maps the M-flow to the M=1 flow: `(q(t), p(t)) = (q̃(t/√M), √M p̃(t/√M))` with initial `p̃₀ = p₀/√M`. With `p₀ = 0`, the **continuum path image in q-space is exactly M-independent**; only traversal speed changes.
*Verified (Toy B):* turning-point gap between M=0.25 and M=4.0: **1.07e-4** (Newtonian) and **1.07e-4** (relativistic, c=5) — pure ε-discretization residue; frequency ratio **3.993** / **4.007** vs the exact √16 = 4.
*Consequence:* mass-only keys discriminate via **timing/frequency reads** or not at all (at p₀=0); the vision's "select the appropriate mass particle" is really "select the appropriate (m, p₀) energy-and-timescale budget".

**Prop 2 (energy-shell gating; proven + verified).** The reachable set of address `a` is contained in the connected component of `{q : V(q) ≤ E(a) − min T}` containing `q₀`. Mass gates access: crossing a barrier `h` from rest-level requires `p₀²/2M > h` ⇒ threshold `M* = p₀²/2h`.
*Verified:* predicted `M* = 0.36`; sweep crosses at M=0.34 and confines at M=0.38. **Heavy particles are provably confined to their home basin — selective retrieval has a hard physical guarantee that attention lacks** (softmax mixes every key; a sub-barrier particle *cannot* read a foreign item).

**Prop 3 (reach/latency; proven, from F5 Prop-1).** The governor caps `|q̇_i| ≤ c/√M_i` ⇒ N-step reach `≤ Nεc/√M_i` per channel. Mass is a **scope key**: heavy = local read (and long latency to distant content), light = global. Wormholes implemented as potential couplings (`IntraWormholePotential` is one) modify the topology of `{V ≤ E}` without touching symplecticity or H-conservation — **wormholes are conservation-safe**; they break *locality*, not the physics guarantees (the paper's "controlled break of conservation" framing applies only to jump-style implementations, not to the built one).

**Prop 4 (gradient dichotomy; proven + verified — the crux objection, answered).** The γ=0 Verlet tangent map is symplectic ⇒ singular values pair as `(σ, 1/σ)` ⇒ **‖J_N‖ ≥ 1 always: a conservative read has no vanishing-gradient problem, ever.** Growth: regular (integrable, shear-dominated) motion ⇒ algebraic, exponent 1; chaotic ⇒ `e^{λNε}`.
*Verified (Toy C, exact tangent maps):* quartic well log-log slope **1.0014** (prereg 1.00±0.15); Hénon–Heiles chaotic λ = **0.098** (prereg [0.02,0.15]); at horizon t=1000 the chaotic ‖J‖ is **10^47.6** vs regular **10^2.8** — 44.8 orders apart.
*Consequence:* **BPTT-through-rollout is usable exactly where the memory lives.** Basins, coset registers, and invariant tori are regular; the pathological regime is chaotic transport between them. The Head's iterative weak-form learning story is consistent — provided reads are launched into (or relaxed into) regular structures, with lr ~ 1/N scaling. This *also* explains why CLU's "long-horizon non-decay" selling point does not doom the gradients: the non-decay comes from `|λ|=1` marginal (regular) dynamics, not from chaos.

**Prop 5 (contraction kills address gradients; proven + verified).** For γ_r>0 the read endpoint is the basin fixed point — locally **constant** in `(q₀,p₀,m)`; residual gradient through a finite window decays as `((1−γ_r)|λ_int|)^n` (≈e^{−18} for γ_r=0.02, n=900 — below any FD/SGD noise floor).
*Verified (Toy D damped arm):* **0/18 with the loss frozen at 7.9035443 to 7 significant digits across 4000 GD steps** — a literal zero-gradient plateau — versus the γ=0 arm, which moves (loss 7.90→2.65 median, 9/18 basin-level). Exactly as pre-registered (P5b). **The folk BPTT objection is inverted: dissipative reads are the unlearnable ones.** Design consequence: learn addresses under γ_r=0 (or tiny), *deploy* content-addressable retrieval under γ_r>0.

**Prop 6 (multiplexing lifts the D1 gauge; proven + verified to machine precision).** With one global `(V, M)`, mass is gauge (`log ω² = log k − log M`) and D1 freezes it — N7's measured fate. With **K items sharing one landscape but carrying per-item masses**, only the *overall scale* remains gauge; all ratios are wake-visible. GD dynamics decouple: the difference coordinate converges at rate `2η_m` independent of the fast lever.
*Verified (Toy E):* `|d − d*| = 2.2e-14`; the scale coordinate collapses with partition **0.047619 = 1/21** — my registered `1/11` was **wrong** (P6b failed): with K items the shared fast lever receives a K-fold richer gradient, so the correct partition is `η_m/(η_m + Kη_k)` (K=2: 1/21), which matches the measurement to 13 digits.
*Consequences:* (i) **the D1/frozen-mass threat does not doom addressing — it constrains the architecture**: masses must be per-address (codebook entries), not global; then the addressing keys train even though the global mass scale never will; (ii) **D1 scale-collapse worsens linearly in the number of items served by the shared lever** — anyone extending the anti-collapse §5.1 partition to multi-item settings must use the K-dependent form; (iii) the Head's "allow arbitrary choices where they don't affect performance" is exactly the surviving gauge (the scale): pin it (deadband) and let ratios restructure.

## 3. Item 2 — is the addressing learnable (weak form)? **SPLIT VERDICT: within-basin & write-side yes; blind cross-basin address search measured dead (4 protocols)**

Four conditions are *necessary* (each has a measured counterexample when violated); §5 shows they are not sufficient for cross-basin capture under any tested optimizer — the surviving learnability story is derived-addresses + write-side restructuring + retry-as-capture. Verdict assembled from Props 4–6 and Toys C/D/F:

1. **Reads must terminate in regular structures** (they do, by construction, for all three write modes) and gradient horizons must respect the chaos budget: usable horizon `N* ≈ (1/λε)·ln(1/η)` through any chaotic transit. Descending over epochs (weak form) tolerates roughness that one-shot recovery would not — Toy D's GD descends a landscape with separatrix roughness (grad-clip needed: FD gradients near separatrices hit the 5.0 clip) and restructures *at basin level* (9/18); the rough separatrix layer is precisely where its strict form dies (§5).
2. **Averaged/smoothing readouts.** The pre-registered pointwise-position probe overfit oscillation phase (P4b failed as registered: acc 0.50 at K=8, train acc 1.0 — pure phase overfit); the **time-averaged linear read is phase-invariant and perfect (1.00 at K=8)**. Retrieval losses for address learning should be built from time-averaged/spectral linear functionals, not pointwise latents.
3. **Per-address masses** (Prop 6). Otherwise there are literally no keys to learn (shipped state).
4. **γ_r = 0 during address learning** (Prop 5).

**Toy D (the crux number, pre-registered P5a ≥ 50%): FAILED as registered — 2/18 strict success (11%).** 18 deliberately-bad addresses (wrong basin, 3 basins × 6 jitters), plain GD on `(q₀,p₀,log M)` through the full 1200-step rollout, window-mean read, K=4 landscape. What the run actually shows (`toyD_results.json`):
- **Escape + transport succeed:** median loss falls 7.90 → 1.3–3.0 and **9/18 inits end with their window-mean nearest the TARGET** (basin-level success 50%) — the derived energy-uphill mechanism operates (GD raises `‖p₀‖`, the mean migrates off the wrong center toward the target).
- **Capture fails:** strict success (confinement in the target well, loss < 0.09) only 2/18. The 7 near-misses circulate at supra-saddle energy; completing retrieval requires *shedding energy while positioned over the target* — a separatrix crossing with fractal basin boundaries, i.e. the one rough sub-problem in the pipeline. The loss traces are non-monotone in exactly that phase (1.3 → 3.2 overshoot).
- **Adam is worse, not better: 1/18** (P5c ❌ — adaptive per-coordinate steps amplify the separatrix roughness rather than averaging it).
- **Damped arm: 0/18 with the loss frozen at 7.9035443 to 7 digits for 4000 steps** (P5b ✓ — Prop 5's zero-gradient plateau, observed raw).

**Content- vs location-addressable.** Both exist natively, split by γ_r (§1). The transformer analogy needs content-addressable: that is the γ_r>0 mode — query embedded as `q₀`, relaxation finds the nearest basin = nearest-stored-item retrieval (Hopfield-exact). The *address selector* (query → `(m,q₀,p₀)`) is then an amortization of this relaxation and can be trained by distillation from it — a concrete training story that avoids backprop-through-relaxation (which Prop 5 forbids anyway).

**NTM/DNC comparison (1b).** Continuous restructuring does sidestep *hard* addressing instability, but the discrete choice does not vanish — it reappears as basin identity, with plateaus inside basins and cliffs at separatrices. What CLU has (and NTM never had) is the **energy-shell escape**: raising `p₀` continuously merges basins (the loss path through "cover several items, then re-localize" is connected), a *physical annealing* rather than a softmax blur. ## 4. Item 3 — capacity and interference: three regimes, measured

Toy A (2-D ring landscape, R/s ≈ 5.7, jitter σ=0.12, time-averaged linear read; `physical` = probe-free nearest-center-of-window-mean):

| K | 2 | 4 | 8 | 16 | 24 | 32 | 48 |
|---|---|---|---|---|---|---|---|
| window-mean read acc | 1.00 | 1.00 | 1.00 | **0.49** | 0.96 | 0.89 | 0.73 |
| physical selectivity | 1.00 | 1.00 | 1.00 | **0.77** | 0.96 | 0.90 | 0.74 |

- **Regime 1 — barrier-protected (K ≤ K_pack ≈ 2πR/4.4s ≈ 8):** selectivity 100%, guaranteed by Prop 2 (E below saddles; a written particle *cannot* visit a foreign item). Long-horizon survival exact (N=20 000 = N=2000). Packing bound in d dims: `N_items ≤ (1+2R/w)^d` — **exponential in latent dim**; capacity in *count* is not the obstruction.
- **Regime 2 — washboard death zone (K ≈ 16 here):** partial well merger leaves finite azimuthal barriers; 17.2% of items are transported ≥1 sector by the residual washboard force (measured `debug_washboard.py`) and selectivity crashes to 0.49–0.77 — **the worst regime is intermediate packing, not maximal packing.** This is exactly where v5-gate found the emergent register (2–3 washboard minima, 1–1.6 bits): **an emergent CHLU is stuck in regime 2.**
- **Regime 3 — continuum register (K ≥ 24):** wells merge into a ring valley; the azimuthal direction is Goldstone-like and the *written angle is retained exactly* (measured drift ≥1 sector: **0.000** at K=24 and K=48). Selectivity recovers to 0.96 and then degrades only because the **write jitter** (σ_ang = σ/R = 0.06 rad) approaches the sector size (0.13 rad at K=48) — capacity is now **resolution-limited, not dynamics-limited**: `K_max ≈ circumference / (≈4·max(σ_write, ℓ_θ))`, with `ℓ_θ = ε√(T/M)/(γ r*)` the t-lever thermal resolution at T>0.
- **Interference between write and stored items** is the real constraint and it is a θ-space, not phase-space, phenomenon: retrieval interference is barrier-controlled (above), but *writing* item B through an MLP `V_θ` moves V globally (no locality; CM-6 erosion is the measured instance). §6 addresses locality.
- **Transformer implication, said plainly:** with emergent structure the honest per-register capacity is **1–1.6 bits** and the system sits in regime 2 — *not* a transformer competitor. With designed/structured registers, per-register capacity is `log₂(range/ℓ_θ)` bits (tens of bits at the measured ℓ_θ scales) with ∞ retention, item count scales exponentially in d, and read isolation is guaranteed. **The competitor claim is conditional on designed-in structure — which is the SDR-prerequisite conclusion (§7) restated.**

Protocol and numbers as in §3 (P5a ❌ 2/18 strict; 9/18 basin-level; P5b ✓ 0/18 frozen; P5c ❌ Adam 1/18).

GD must therefore end its trajectory-through-address-space on the small-measure, low-energy manifold, and the approach crosses the separatrix region where the conservative loss is genuinely rough (this is the one place the Prop-4 chaos budget bites — separatrix layers are the chaotic set). Plain GD gets stuck circulating; Adam's per-coordinate rescaling makes it worse.

**The naive hybrid repair FAILS TOO (post-hoc follow-up, NOT pre-registered — labeled as such):** protocol: keep the conservatively-GD-learned addresses, retrieve with a damped read (γ_r = 0.02, 4000 steps); success = settled point nearest target. Result (`toyD_hybrid_results.json`): **3/18 (0.167) — at/below the 0.25 chance level** (all 18 settle; the capturing basin is quasi-random). Interpretation rule committed in the draft before the number arrived: *"if the hybrid adds nothing over 2/18, the capture failure is fundamental at this protocol and the crux verdict is open, tilted negative."* **That branch fired.** Mechanism: the GD-learned addresses are supra-saddle circulating orbits; dissipative relaxation from supra-saddle energy is chaotic scattering with fractal basin boundaries — which basin captures is uncorrelated with the window-mean bias that GD optimized. The transport phase biases the *trajectory mean*, not the *capture basin*.

**The energy-annealed repair FAILS AS WELL (Toy F, exploratory, prediction committed in-script before running: ≥6/18 — measured 0/18).** Loss `L_t = ‖window-mean − c_target‖² + β_t·softplus(E(a))` with the *closed-form* address energy `E(a) = V(q₀)+‖p₀‖²/2M`, β ramped 0→2 over 4000 steps. What happens (`toyF_results.json`): the penalty forces capture into **whichever basin the orbit currently occupies** — 8/18 end at wrong-well bottoms (final E ≈ −0.79, task loss ≈ 7.9–15.8) — while elsewhere the task gradient fights the squeeze and keeps E high (up to 19.4). Energy annealing solves "shed energy," not "shed energy *over the target*" — the coordination between position and squeeze timing is itself the rough sub-problem. **What this redirects (the design consequence, not a eulogy):** the vision does **not** actually require cross-basin address *search*. Three bypasses, in order of strength:
1. **Derived addresses (recommended).** The writer knows where it wrote: `q₀ᵢ` is *computable* from `V_θ` (the basin minimum, obtainable by relaxation), not a free parameter to be searched for. Make the codebook a **function of the landscape** (`aᵢ = derive(V_θ, i)`), and let training restructure the *landscape* (rich, smooth, D1-favored gradients — exactly the lever that trains best in this program) with addresses tracking it. Cross-basin moves then happen in θ-space, where they are continuous deformations, not separatrix crossings.
2. **Retry-as-capture.** The Head's boost-retry cascade (stage 8) is derivative-free selection over energy shells — immune to separatrix roughness by construction. Retries are not a luxury on top of gradient capture; **they are the replacement for it.**
3. **Within-basin-only address learning.** If write-time bookkeeping initializes every address in the correct basin, only within-basin refinement remains — smooth and easy (the 2/18 successes and near-misses show within-basin descent works). The Head's "encode to an arbitrary region and restructure" survives *iff* the restructuring is done by the write side; blind read-side address search across basins is the one measured-dead path.

## 6. Item 4 — the three write modes, made concrete

| mode | landscape realization | write current | permanence dial | corruption of neighbors |
|---|---|---|---|---|
| (a) permanent latch | **designed** coset direction, `μ² = 0` exactly (SO2-invariant block; CM-9 block-untied) | F5/Prop-17 equivariant write current: tilt along the symmetry orbit; moves the register value at zero stiffness cost | none needed — `τ=∞` at T=0 for all γ (Cor-13, verified ≤1.7e-14); at T>0, `n₁/₂ ∝ γ/T` (choose γ high inside a designed vault: v5-gate 107.77×) | zero *within* a block-untied register by construction; **cannot be realized emergently** (N46/D3; 12-order flatness gap) |
| (b) half-life, written near an item | **pseudo-Goldstone**: explicitly break the (a)-symmetry by a controlled spurion δ ⇒ `μ²(δ)` via GMOR (`μ²F² = δΣ`); retention `n₁/₂ ∝ 1/μ²` (T=0 relaxational) or the V-curve at γ>0 | the same equivariant current + the spurion knob; "near" = same coset orbit, offset along it | `λ`/δ of the breaking term is the half-life dial (R-4's finite-λ residual is *exactly* this — the "defect" of R-4 as a latch-maker is the *feature* here) | the spurion must live in the register block only; a *global* spurion tilts the parent latch too — the (b)-corrupts-(a) risk is real for MLP V_θ (no locality) and vanishes only under parameter separation (CM-9) or basis-orthogonal spurions (`⟨∇V_spurion, ∂_orbit V_a⟩ = 0`) |

**The locality problem, said precisely:** an MLP potential has global support, so *every* write perturbs *every* stored item (measured instance: sleep-phase erosion CM-6; and the fit-gap N13 finding that the friction rung's damage to the register came through V-perturbation, not friction). Three admissible fixes, in program order of preference: (i) **structural blocks** (designed register + RBF/dictionary wells — write = add/move an atom: exactly local); (ii) **anchor stored items during writes** (R-2/R-3 as write-time protection, measured envelope λ=100 holds 5/5); (iii) NTK-orthogonalized write currents (project δθ out of stored items' tangent features — O(items·params), expensive, unproven).

## 8. Items 6–7 + the feasibility table

**Consolidation (6i).** Non-interacting particles (CLULattice as shipped): consolidation is an ordinary learned readout ψ on the trajectory bundle — nothing in the physics obstructs or helps; it is as learnable as any supervised head. Interacting particles: the XY line applies — **only topological content is thermodynamically stable under coupling** (xy-lattice-theory §4.5), 1-D consolidated memory degrades with size (τ∝N^{−0.7} measured), 2-D improves below T_KT (slopes +3.5…+5.0 measured on the real path). If consolidation is ever implemented as *coupling*, the stored quantity must be winding-type, and the lattice should be 2-D.

**Boosts (6ii).** A boost is an affine symplectic re-address `a ↦ S·a`: volume-preserving, so it does not change the *information capacity* of the read — but H is not boost-invariant, so it changes `E(a)`, hence the reachable component (Prop 2). **A boost ladder is an energy-shell filtration: retry k unlocks precisely the items behind barriers < E_k.** That is a principled retry semantics: memory is hierarchically organized by barrier height, and retries walk up the hierarchy. (It changes *what is retrievable*, not merely the readout frame — resolving the task's either/or.)

**Wormholes (6iii).** As built (potential couplings): conservation-safe (Prop 3); they reconnect `{V ≤ E}` so a single particle can gather from regions that would otherwise need a boost of barrier-crossing cost. Guarantee-compatible. Unknown empirically whether the coupling can be learned to connect the *right* regions (same D3-flavored risk as everything emergent).

**Decorative-CLU (item 7).** The referee-proof mechanism is an **information budget**: make the required payload strictly exceed the address capacity. The address carries ≤ `(2d + d_m)` reals of query-dependent information through the φ bottleneck; if the task answer requires `≫` that (e.g. reproduce a stored waveform/pattern of dimension ≫ 2d), the excess bits can only enter the trajectory from `V_θ` — the rollout is then load-bearing *by counting*. Enforce by: dim-capping φ's output to the address alone (no side channel to ψ), and ψ seeing only the trajectory. Ablations that certify it: (i) identity-rollout (ψ sees `q₀` repeated) — must fail; (ii) random-V — must fail; (iii) trained-V, shuffled codebook — must fail selectively. **Honest note: on FD001 today CLU fails test (i) in spirit** (raw-stats encoder 0.7486 > all CLU arms; clu-cafe-integration) — the current pipeline is decorative, which is precisely the Head's architectural-gap diagnosis; the memory architecture is the repair, and the payload>address principle is what makes the repair falsifiable.
